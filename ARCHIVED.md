# VuReact Project Archive Notice

VuReact has been discontinued and archived. The project once aimed to compile Vue 3 components into React code and explore gradual migration solutions.

After archiving, compatibility, security updates, or issue fixes are no longer guaranteed. The repository contents are provided only for learning, research, and archival reference; before using them in production projects, please evaluate and maintain the required code yourself.

If you wish to continue maintaining or developing based on this project, please fork the repository and assume all subsequent maintenance work yourself.
